PhishGuard

python · stdlib only

transparent, rule-based email analyzer.

PhishGuard is a transparent, rule-based email analyzer designed to classify messages as Safe or Phishing. The focus is on clean logic, explainability, and zero third-party dependencies — leveraging only the Python standard library.

how it works

  • parses single raw .eml, folders, and mbox archives
  • runs a stack of rules: sender mismatch, lookalike domains, keyword analysis, suspicious links, attachment types
  • each rule contributes a weight & reason — final verdict shows the full reasoning
  • no ML, no cloud calls — auditable end-to-end
